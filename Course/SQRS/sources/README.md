# Original SQRBOK revision questions

The `RQ*.md` files and `rq-l10-bank-dfd.svg` are unmodified source snapshots from [sqrbok/sqrbok-preview](https://github.com/sqrbok/sqrbok-preview/tree/506d4f5ba880cfb21311e12069510df5c2a71b80/content/material/sqr), commit `506d4f5ba880cfb21311e12069510df5c2a71b80`.

Question sections are copied without paraphrasing into the lecture decks. Only inter-question dividers are omitted; headings, scenario text, values, subquestions, code and tables are retained. The course Markdown wraps each original section in an Obsidian question callout and pairs it with a separately authored self-check answer. The SVG is embedded in the offline HTML rather than loaded from the network.

`source_manifest.json` in the parent directory records SHA-256 checksums for every source snapshot and asset, plus the published heading anchors used by exact-question links. Normal builds and tests are offline. `tools/sync_questions.py --fetch` re-fetches the pinned revision files and verifies the question anchors against the published pages.
